# Hand-drawn theme prototype assets

These local assets belong to the throwaway HTML prototype, not the plugin build.

- `rough-4.6.6.js`: Rough.js 4.6.6, from https://unpkg.com/roughjs@4.6.6/bundled/rough.js. MIT license in `rough-LICENSE.txt`.
- `SketchNotesDemo.woff2`: a renamed, demo-text-only subset of [CEF Fonts CJK / 快去写作业](https://github.com/Partyb0ssishere/cef-fonts-cjk), by PartyB0ssishere. Original font: `CEFFontsCJK-Regular.ttf`, Git blob `a634f8a42b36d92ed86f626919ab5fdc1bfeaa9e`. SIL OFL 1.1 in `font-OFL.txt`. Font family renamed to `Sketch Notes Demo` during subsetting. This is not a complete font for arbitrary Canvas content.

The prototype loads these assets locally and makes no external requests. Keep this directory beside the HTML file when copying the demo.
