# 上游项目与致谢

Better Canvas 的部分功能方向参考了以下开源项目。功能方向参考不代表已完整兼容上游，也不代表当前代码整体直接复制自这些项目。

- [Advanced Canvas](https://github.com/Developer-Mike/obsidian-advanced-canvas)：Canvas 增强、样式和工作流工具。上游仓库声明 GPL-3.0。
- [Canvas MindMap](https://github.com/Quorafind/Obsidian-Canvas-MindMap)：思维导图节点创建、导航和布局。其 `package.json` 声明 MIT；在记录这份说明时，未发现仓库根目录的 LICENSE 文件。
- [Obsidian AI Canvas](https://github.com/testy-cool/obsidian-ai-canvas)：Canvas 上的 AI 问答与图像生成。上游 LICENSE 声明 MIT。

本项目自身的许可证见根目录 [LICENSE](../LICENSE)。如果后续直接引入上游代码或资源，应在引入前核对当前有效许可证，并保留所需版权和许可声明。
