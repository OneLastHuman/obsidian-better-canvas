# 功能指南

本文按工作场景介绍 Better Canvas 的主要功能。具体实现状态和仍待验证的兼容性差异，请参阅 [功能整合矩阵](INTEGRATION_MATRIX.md)。

## 设置

设置页沿用 Obsidian 原生的设置行、分组标题和控件，上方分为四个入口。文字与控件分别对齐，页面使用宿主的滚动区域；没有第二层侧栏或固定高度。Obsidian 1.11 及以上使用原生 `SettingGroup`，较早版本回退到原生 `Setting` 标题和设置行。

### 首次使用引导

- 首次启用插件时显示一次欢迎入口，提供创建示例画布、打开内置快速入门和暂不设置。关闭、完成或跳过后不会在每次启动时重复显示；可从命令面板运行 **打开首次使用引导**。快速入门直接显示在插件内，无需复制仓库文档到 Vault。
- 示例画布写入 `Better Canvas/快速入门.canvas`，包含文本卡、连线、主题入口和节点样式入口说明。目标名称已占用时生成编号名称，不覆盖现有文件。插件记录最近创建的示例路径，之后优先打开该文件。
- 首个空画布显示一次可关闭提示，指出画布主题、节点样式、`Tab` 和 `Enter`。显示时即记录状态，打开其他空画布不会重复提示；创建卡片后当前提示消失。**设置 → Better Canvas → 操作 → 首次使用** 可重置引导。
- 引导状态只保存在本地插件配置中。重置引导不会删除画布、示例文件或 AI 设置。

| 入口 | 内容 |
| --- | --- |
| 画布 | 文字对齐、自动布局方向、水平/垂直间距、网格间距 |
| 操作 | 子卡片/同级卡片创建、相邻卡片导航、方向创建、只读菜单与视图锁定 |
| AI 助手 | 使用方式、模型服务与默认模型；按需展开生成参数、回答偏好、图片生成、学习卡片、外部工具 |
| 文件 | 笔记链接索引、按笔记属性自动连线、导出清晰度与背景 |

修改先保留在草稿中，切换分类不会丢失；点击底部 **保存更改** 后生效，或用 **放弃更改** 恢复当前已保存设置。服务编辑弹窗的 **完成** 只更新草稿，**取消** 不修改原配置。低频选项默认折叠，展开状态会在当前设置页操作中保留。

初始宽高、自定义色板、全局自定义 CSS、节点模板与 YouTube 字幕导入已移除。已有 Canvas 内容、尺寸和样式保持不变；旧配置中的相关字段保留供恢复，但不再影响运行。主题和节点样式面板继续可用，CSS snippet 定义的节点/连线样式预设不受影响。

## 1. Canvas 编辑与组织

### 节点与连线

- **节点外观：** 设置颜色、形状、边框、文本对齐和 CSS 类。
- **连线样式：** 设置颜色、线型、箭头，翻转关联边的方向，并选择 direct、square 或 A-star 路径。
- **布局与交互：** 网格对齐、自动调整文本节点尺寸、层级排序、焦点模式和交互锁定；支持 floating edge 自动重定位。
- **CSS 样式预设：** 通过已加载的 CSS snippet 为节点或连线定义可重复应用的属性。格式和示例见 [自定义样式预设指南](CUSTOM_STYLE_PRESETS.md)。

### 节点样式面板与默认尺寸

- **样式面板：** 点击 Canvas 右侧原生控件栈中的调色板按钮，在控件左侧打开面板。未选中节点时，点击预设会在视口中心新建一张空白文本卡片；也可以将预设拖入当前画布，在落点新建卡片。默认及各主题的预设均支持此操作，创建后自动选中新卡片，创建和样式可一步撤销。拖放新建不会改写原选区节点的样式；放到画布外或取消拖动不会创建卡片。只读画布不允许创建。
- **调整选中节点：** 面板提供预设、颜色、形状、边框和文本对齐。选中节点后，点击选项立即应用到选区，并写回 Canvas 节点数据；样式不一致时显示混合状态。无选区时，颜色、形状、边框、对齐、填充和纸面浓度等单项控件仍禁用。连线选区和节点、连线混合选区不支持打开节点样式面板。点击面板外部或按 Esc 可关闭面板。右键节点仍使用 Obsidian 原生菜单。
- **固定创建尺寸：** 插件新建空白文本卡片使用 280 × 140，旧的全局宽高配置不再参与创建。已有卡片、克隆和手动调整后的尺寸保留；部分 AI、Portal 和 PDF 内容节点仍按内容决定尺寸。原生拖拽创建仍由 Obsidian 控制。
- **自动调整尺寸：** 新建文本节点默认启用自动调整尺寸。宽度限制为 80–440 px，高度限制为 44–560 px。单行文字居中，多行文字左对齐。空节点保持创建尺寸；手动拖动角点会关闭该节点的自动调整。可用“切换所选节点自动调整尺寸”命令重新开启或关闭。
- **按当前样式测量：** 默认主题的常规矩形纯文本卡片沿用“文字宽 + 48”和“行数 × 24 + 20”的规则，单位为 px。主题卡片按实际 Markdown、字体、内边距和形状的文字安全区测量。切换主题或预设、更新 CSS、字体加载完成后，已启用自动调整的卡片会重新排版。编辑中的卡片在退出编辑后测量。只读画布和已关闭自动调整的卡片保留尺寸。
- **换行与滚动：** 自动调整会更新文字对齐和预览内容高度。手动改动文字对齐后，下次自动调整仍按实际行数判定。达到 560 px 高度上限后，长内容仍可滚动查看。
- **输入范围：** 设置值超出输入框显示的范围时会标记为无效，不会保存。修正数值后才会应用。

### 画布主题

- **切换主题：** 点击画布右侧的“画布主题”按钮，或运行“切换当前画布主题”命令。可选默认、拼贴手账、手绘白板、软糖白板、纸本研究和柔软便签 6 种主题。空画布也可以切换；主题保存在当前 `.canvas` 文件中，按画布独立生效。
- **拼贴手账：** 暖纸色背景、细纸纹、棕色墨线与箭头、纸签式连线标签和虚线分组。Obsidian 使用深色外观时，画布仍保留浅色纸面和深色文字，编辑态保持可读。
- **五种纸片预设：** 选中卡片，打开「节点样式」，可以选择胶带便签、横线纸、撕边纸、照片框或标签。面板提供配套的十种低饱和配色，支持批量应用。分组使用统一的分组样式；纸片预设只应用于普通卡片。
- **手绘白板：** 白纸点阵、轻微抖动的手绘轮廓、排线或交叉排线填充，以及本地打包的中文手写字体；不请求远程字体。深色外观会切换为深色纸面和浅色墨线。节点文字默认使用加粗手写体，编辑框和导出使用同一字体。
- **六种功能预设：** 选中一个或多个卡片，打开「节点样式」，可以选择章节标题、核心概念、行动步骤、判断分支、旁注说明或风险提醒。每种预设固定形状、颜色、边框、填充和对齐方式，适合快速搭建流程图和说明板。可以再用颜色、形状、边框、对齐和填充选项单独微调；分组节点不套用功能预设。多选混合样式会显示为混合状态。
- **软糖白板：** 暖白点阵、大圆角、4 px 深色描边和柔和色块；深色外观使用中性石墨画布、柔和粉彩节点、深色文字与描边，以及浅灰蓝连线。「节点样式」提供六种不同轮廓的预设：起止／主题（胶囊）、步骤／任务（圆角矩形）、判断／分支（圆角菱形）、流转／下一阶段（宽箭头）、输入／输出（平行四边形）、文档／产出（波浪底）。缩略图直接展示功能形状，支持多选、混合状态及颜色／形状／边框／对齐微调，分组不套用预设。预设只表达视觉语义；判断条件和是／否连线需要手动创建。拖动角点调整尺寸时，卡面裁形、描边、选中光环和文字安全区逐帧跟随指针；选中光环与卡片保持固定像素间距，并沿当前形状的直边、斜边和尖角等距。
- **纸本研究：** 暖白纸面、宋体标题与正文，配套陶土红、麦穗黄、雾蓝、橄榄绿和莓果灰。深色 Obsidian 外观下仍保留浅色纸面。六种预设为文献资料、重点引文、阅读批注、核心观点、待解问题、章节标题；分别强调装订色边与内框、引用衬底、横线与页边线、深色标题带、圆角虚线和开放标题版式。标题带只处理原文开头已有的 Markdown 标题，引用样式只处理已有引用块；不补充标题、编号、来源或装饰文案。
- **纸本预设操作：** 在「节点样式」选择缩略卡片，悬停可查看名称和说明；支持多选、混合状态以及柔和／标准／浓郁三档纸面色彩浓度。浓度影响引文、批注和问题卡的底色，资料与观点卡保留暖白底。随后可继续调整颜色、形状、边框和对齐。分组不应用卡片预设；空选区可点击或拖动预设新建卡片，纸面浓度需选中卡片后调整。
- **柔软便签：** 浅彩曲线卡片与透明文字，无描边和阴影。6 种预设为灵感卡、摘录卡、概念卡、行动卡、问题卡和自由文字。预设只应用于文本节点；支持批量应用、颜色与文字排列调整。行动卡可使用 Markdown 任务清单。
- **保留手动设置：** 应用预设只更新所选节点的视觉字段。已有内容、位置、连线和未知字段保留。已启用自动调整的卡片会按新样式重新计算尺寸和文字对齐；手动尺寸保留。主题和预设操作支持原生撤销／重做，后台自动调整不增加独立的撤销步骤。
- **示例画布：** [示例索引](examples/README.md) 提供 6 种主题的展示画布和主题功能样例。按索引中的路径复制图片，可保留画布的图片引用。

主题的导出和兼容性范围：

| 主题 | 全部内容／选区静态导出 |
| --- | --- |
| 手绘白板 | SVG 和 PNG 保留节点轮廓、填充和连线 |
| 软糖白板 | SVG 和 PNG 保留节点轮廓、填充和连线；固定浅色配色，可指定画布背景 |
| 纸本研究 | 保留纸面配色、预设轮廓、装订边、标题带和基础排版；引用块、复杂 Markdown／表格与宿主渲染不完全一致 |
| 柔软便签 | 保留曲线轮廓、颜色、文字及内嵌字体；任务标记为静态内容，不能点击 |
| 拼贴手账 | 纸纹、胶带等装饰依赖宿主 DOM，静态导出暂不还原 |

所有形状继续使用 Canvas 原生矩形连线端点、框选和拖拽范围。平行四边形斜边与端点可能有间隙。自动调整会计入受支持形状的文字安全区，宽高上限仍为 440 × 560 px。封顶长内容可滚动。

各主题的验证覆盖不同。视口导出、移动端和第三方 Obsidian 主题的验证范围见 [功能整合矩阵](INTEGRATION_MATRIX.md)。

### 搜索、导航与批量操作

- 搜索 Canvas 中的文本、文件路径和链接。
- 浏览当前 Canvas 的外链与反向链接，并将唯一目标批量添加为文件、网页或文本节点。
- 按左、右、上、下方向克隆所选节点并自动连接；可保留原节点内容、样式和扩展属性。
- 对多节点选区做水平或垂直翻转，也可以交换两个节点的中心位置。
- 一次选中 Canvas 中的全部连线；缩放以适应整个画布，并恢复操作前的选区。
- 按节点顺序进入演示模式。

### 分组、Portal、元数据与导出

- 创建独立分组并折叠或展开分组；将选区封装为单独的 Canvas。
- 创建 Canvas Portal，查看并编辑另一个 Canvas 的镜像内容。Portal 的适用范围与限制见[已知限制](KNOWN_LIMITATIONS.md)。
- 编辑 Canvas frontmatter：逐属性新增、修改或删除，也可以编辑完整 JSON 对象。
- 导出 JSON Canvas；导出当前视口、全部内容或仅选中节点的 PNG/SVG。选区导出只包含所选节点及其内部连线。

静态 SVG 渲染可处理常见节点形状、文字、连线、箭头及 direct、square、A-star 路由。导出会在体积预算内嵌入 PNG/JPEG/WebP/GIF 图片与 PDF 页面栅格预览。固定 PDF 页面使用对应页码，普通 PDF 节点默认预览第一页。常见 Markdown 粗体、斜体、链接、标题、任务清单和列表会转换为静态图像可读文本；交互式 HTML 不会执行，代码会以文本形式显示。复杂画布的导出效果仍取决于节点数量、资源大小和 Obsidian 渲染行为。

## 2. 思维导图

- 为选中节点创建子节点、同级节点或游离节点。
- 将 Markdown 文件中的 H1 标题拆分为相关联的节点。
- 选择节点树，并按 LR、RL、TB 或 BT 方向进行基础自动布局。
- 未编辑节点时，按 Tab 创建子节点，按 Enter 创建同级节点；编辑卡片文本时，按 Shift + Tab 创建子节点，按 Shift + Enter 创建同级节点。Alt + 方向键用于导航节点，Ctrl/Cmd + Shift + 方向键用于创建指定方向的子节点。
- 按指定方向克隆并连接节点，同时保留原内容、样式和扩展属性。
- 生成思维导图结构和复习闪卡。闪卡默认保存为关联 Canvas 节点；也可导出为 Obsidian Spaced Repetition 兼容的 Markdown 卡组。卡组支持主题标签、目录设置和防覆盖的重名文件处理。

快捷键列表见 [README](../README.md#常用快捷键)。可在 **设置 → Better Canvas → 操作** 中分别关闭子节点创建、同级节点创建、Alt + 方向键和 Ctrl/Cmd + 方向键快捷键，以免与其他插件或个人热键冲突。

## 3. AI 工作流

### 节点问答与生成

- 根据选中节点及其相邻关联内容提问，并把回答保存为连接到原节点的新节点。
- 单选或多选节点后，右键菜单的 AI 分组提供问 AI、生成图片和生成闪卡。多选时合并所选节点及其直接相邻节点的上下文，共享的相邻节点不会重复加入；同时选中的连线不计入源节点。回答、图片和 Canvas 闪卡会放在选区右侧，并连接到各个源节点。闪卡的 Spaced Repetition 导出模式仍输出一个 Markdown 卡组。命令面板同样支持多选。
- 多选提问面板显示所选节点数量，并固定本次选中的节点和画布。提问及闪卡沿用首个所选节点的供应商和模型配置；图片仍使用独立的图片服务设置。上下文沿用每节点最多 3000 字符、合计最多 14000 字符的限制，图片生成使用前 7000 字符；视觉输入合计最多 4 张图片或 PDF 页面。
- 单个 AI 回答节点的右键菜单会显示重生成。多选生成的回答会保存全部源节点，重生成时重新读取这些节点的上下文。只读画布或已被删除的源节点会阻止新请求。
- “问 AI”使用简洁提问面板：单行显示当前卡片及相邻节点提示，模型位于输入区左下方（本地后端显示本地配置），圆形箭头按钮用于发送。输入区右下角可拖动调节高度，拖拽角位于发送按钮右下方。三个文字快捷提问会填入输入框；已有内容会保留并追加，点击发送或按 Ctrl/Cmd + Enter 后才生成回答。空白问题不能发送，Enter 可换行，输入法组合期间不会触发快捷发送，Esc 关闭面板。“指定模型并向 AI 提问”使用同一面板。
- 面板按当前后端、来源节点的服务和指定模型显示本地配置状态。API 后端分别检查服务地址、模型和凭据；允许免密的本地 API 不因 API Key 为空而阻止。Codex CLI 与 OpenCode ACP 显示各自的本机配置说明，不声称已检查安装或登录。缺少必需配置时，发送按钮和 Ctrl/Cmd + Enter 使用同一规则：保留问题并高亮配置提示，不静默禁用发送。用户可以从面板进入 AI 设置，保存或放弃更改后点击 **返回提问**；保存或关闭设置不会自动重开面板。当前问题、来源和指定模型在本次往返中保留，返回时重新检查已保存的配置。
- 配置状态只检查本地字段，不代表服务已连接或模型可用。打开提问面板不会自动发送探测请求。
- 支持流式生成、停止生成、重新生成，以及按节点覆盖服务或模型配置。
- 保存多套命名系统提示词，选择并应用，也可通过同名配置更新或删除已有提示词。
- 通过配置的服务生成图片，并将图片保存到 Vault 附件目录后插入 Canvas。
- 导入可访问的网页正文作为后续整理与分析素材。YouTube 字幕导入已移除；Gemini 原生公开视频分析是独立功能，仍可使用。
- 对选定 Vault 文件夹内的 Markdown 文件批量执行同一条 Prompt；每次最多 20 篇，并创建源文件与结果的关联节点。发送文件内容前需要选择文件夹并确认。

### 模型与服务

- 原生 API profile 支持 OpenAI-compatible、Anthropic Messages 和 Google Gemini。
- 支持从 OpenAI-compatible、Anthropic 和 Gemini 模型端点发现可用模型；端点不支持列表查询时，可手动输入模型名。
- 每个 profile 可单独设置 Temperature、最大输出 token 数和高级请求参数 JSON。高级参数仅用于 API 后端的文本请求，并按相应协议合并；核心请求字段和认证字段受保护。Temperature 范围随协议变化（OpenAI 兼容 / Gemini 为 0 到 2，Anthropic 为 0 到 1），在服务编辑弹窗完成接口类型修改后，界面会更新范围并调整超出新上限的草稿值，保存更改后生效。
- 可主动探测服务的文本请求与图片输入能力。探测需用户确认，最多发送两次小型 API 请求，并保存当前 provider/model 的结果。图片输入请求成功不代表模型确实理解了图片，也不能证明图片生成、PDF、视频、URL context 或搜索 grounding 等能力。

详细配置见 [AI 与 MCP 配置指南](AI_SETUP.md)。

### MCP 工具、资源与提示模板

支持远程 MCP Streamable HTTP、旧式 SSE 和本地 MCP stdio。除工具调用外，还可列出分页资源（resources/list）、读取资源（resources/read）、发现提示模板（prompts/list）并带参数解析模板（prompts/get）。文本结果会保存为关联 Canvas 节点，支持的 PNG/JPEG/WebP/GIF 图片会保存为 Vault 附件并创建关联文件节点。

本地 stdio 根据 command、args、env、cwd 配置启动进程；会话按配置复用，最多缓存 4 个本地服务会话，空闲 5 分钟后关闭，插件卸载时清理。工具执行前须检查名称和参数，并仅连接可信服务。

工具参数、提示模板参数以及 styleAttributes / frontmatter 等 JSON 输入框要求 JSON object。输入不是有效 JSON 时弹窗保持打开并保留已输入文本，显示插件措辞的错误提示（不显示解析器原文），修正后可直接重新提交。

### 本地 CLI 与多模态内容

- **Codex CLI：** 桌面端可调用本机已安装并登录的 Codex CLI，在只读沙盒和临时工作目录中分析选中节点及相邻上下文，结果保存为关联节点。设置中可读取模型列表并下拉选择，也可填写自定义模型 ID；普通文本生成和专用分析命令都使用所选模型。
- **OpenCode ACP：** 桌面端可通过 `opencode acp` 进行文本问答和闪卡生成，无需另填文本 API Key。设置中可读取并选择当前会话的模型，兼容新旧 ACP 模型接口。
- **其他本地 Agent：** 支持 Claude Code、Cursor Agent、Gemini CLI、GitHub Copilot CLI、Qwen Coder、Aider 和 IBM Bob。每个 Agent 独立保存程序路径和模型；支持模型覆盖的 CLI 提供预设下拉选项和手动填写，Bob 使用自身模型配置。所有后端均保留默认模型选项，修改后需点击「保存更改」。
- **PDF：** 固定 PDF 页面可提取文本，并将页面栅格图像发送给支持视觉输入的模型。支持按页码或页码范围进行批量 OCR，每批最多 20 页，并为每页保存独立结果节点。
- **Gemini 视频上下文：** Gemini profile 可尝试分析公开视频；视频、模型和账号必须支持对应能力。
- **HTML 预览：** 将仓库中的 `.html` / `.htm` 文件拖入或插入 Canvas 后，文件卡片直接显示页面。文本卡片和 Markdown 文件中的 HTML 代码块保留「HTML 预览」按钮。

本机 CLI 使用各自的模型服务配置，不保证离线处理。本地 Agent 当前只接受文本输入；若所选上下文包含图片或文件，需切回 API 后端。模型预设和工具返回的模型目录不代表账号权限。所有 AI 能力都受服务商 API、模型权限和内容可访问性影响。

### HTML 文件与代码块预览

把 HTML 文件保存到当前仓库，再拖入 Canvas 或通过 Canvas 的文件插入入口选择它。支持 `.html`、`.htm` 及其大写扩展名。文件列表未显示 HTML 时，可在 Obsidian「文件与链接」设置中开启「检测所有类型文件」。

- HTML 文件卡片默认显示预览。点击「隐藏预览」会关闭页面并停止其中的脚本；再次点击「HTML 预览」会重新加载。卡片顶部留有操作区域，页面内部可滚动和交互。
- 保存 HTML 文件后，已打开的卡片自动刷新。重命名由 Obsidian 更新文件引用后继续预览；源文件被删除、为空、读取失败或超过 200,000 个字符时，卡片显示提示，不运行截断后的内容。
- 文本卡片和 Markdown 文件内的 `html` / `htm` 围栏代码块仍需点击按钮才加载，预览第一个非空 HTML 代码块。直接粘贴未加围栏的 HTML 源码不会自动转换成预览。
- 预览只读取文件，不改写 HTML 或 Canvas 节点数据。只读画布也能显示预览；隐藏状态仅保留在当前卡片视图中，重新打开画布后 HTML 文件默认展开。
- 页面在不具备同源权限的沙盒中运行。内联 CSS 和 JavaScript 可用于交互；不开放 Obsidian/Vault API、表单提交、弹窗、下载或顶层导航。外部资源仍可能发出网络请求，请只预览可信或已检查的 HTML。
- 优先使用包含内联 CSS、JavaScript 和内嵌图片的单文件 HTML。当前不解析或打包相邻的 Vault CSS、脚本、图片等相对路径资源；外部资源还受浏览器和服务端跨域规则限制。
- PNG/SVG 导出保持静态导出行为，不包含可运行的 HTML 页面。桌面之外的兼容性仍需单独验证。
