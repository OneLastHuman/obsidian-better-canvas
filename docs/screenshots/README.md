## 复现

1. 使用不含私人内容的测试 Vault。
2. 构建当前插件，安装 `main.js`、`manifest.json` 和 `styles.css`。
3. 按[英文示例说明](../examples/readme-showcase/en/README.md)复制画布与插画。
4. 使用浅色 Obsidian 默认主题，收起两侧栏，界面语言设为英文。
5. 打开目标画布，按节点范围居中并保留少量边距。
6. 截取画布区域，与当前 DOM 状态核对；隐藏滚动条与状态栏。

- AI 图仅展示输入界面，不证明上下文传递、生成质量或模型服务可用性。
