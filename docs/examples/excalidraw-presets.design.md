# 手绘白板：六种功能预设设计

已实现：保留第二版的 Rough.js 笔触和中文手写字体。设计已接入 Better Canvas 的按画布主题、节点样式、同源编辑器和静态导出。

参考 [Excalidraw 元素定义](https://github.com/excalidraw/excalidraw/blob/master/packages/element/src/types.ts)：矩形、菱形、椭圆、独立文字；实色、排线、交叉排线；描边、线型、粗糙度和文字对齐。以下六个名称与组合是为 Better Canvas 设计的功能预设，不是 Excalidraw 官方预设列表。

| 预设 | 用途 | 外观 | 配合方式 |
| --- | --- | --- | --- |
| 章节标题 | 组织阅读顺序、标记主题和区域 | 无框、大号手写字、左对齐、短划线 | 作为内容层级，不依赖连线 |
| 核心概念 | 中心主题、实体、讨论对象 | 椭圆、淡蓝排线、居中 | 向相关概念发散连接 |
| 行动步骤 | 流程步骤、操作、待办 | 矩形、淡绿排线、居中 | 顺序箭头表达先后关系 |
| 判断分支 | 条件判断、分支 | 菱形、浅黄实色、短句居中 | 出口连线写“是 / 否”或条件 |
| 旁注说明 | 背景、来源、补充信息 | 无框、小号手写字、左对齐 | 可用虚线指向说明对象 |
| 风险提醒 | 风险、阻塞、待确认 | 矩形、红色虚线、淡红交叉排线、左对齐 | 虚线和填充纹理共同提示待确认状态 |

## 功能交互

- 默认进入六种预设总览；底部可切换原有三个内容场景。
- 点选节点后，点击预设应用形状、填充、颜色和文字排版。节点文字、位置和连线保持原值。
- 更改填充或颜色后标注“已微调”；再次点击预设恢复该预设组合。
- 粗糙度是当前原型的全局参数，六种预设共用获认可的手绘语言。
- 连线样式单独设置。预设中的连线说明是搭配建议，不自动修改相邻节点的连线。
- 标题与旁注仍有可选择的矩形区域。正式接入时继续遵循 Canvas 的矩形交互模型。
- 预设保留 Canvas 原生矩形交互区域；视觉轮廓不会改变节点选择、拖动和连线几何。
