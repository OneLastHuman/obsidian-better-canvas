# 示例画布

本目录提供可在 Obsidian 中打开的 Canvas。启用 Better Canvas 后，再打开复制到 Vault 的示例。

## README 展示示例

[README 示例画布](readme-showcase/README.md) 包含默认、拼贴手账、手绘白板、软糖白板、纸本研究和柔软便签 6 种主题。复制步骤及图片路径见该目录的说明。

## 主题功能样例

| 文件 | 用途 | 复制方式 |
| --- | --- | --- |
| [scrapbook.canvas](scrapbook.canvas) | 拼贴手账纸片预设与图片卡片 | 与 [scrapbook-postcard.svg](scrapbook-postcard.svg) 一起放入 Vault 的 `Better Canvas 主题体验/` 文件夹 |
| [paper-research.canvas](paper-research.canvas) | 纸本研究的 6 种预设 | 复制到 Vault 后打开 |
| [rounded-map.canvas](rounded-map.canvas) | 软糖白板的 6 种功能形状与判断分支 | 复制到 Vault 后打开 |

拼贴手账样例引用固定的 Vault 相对图片路径。更换文件夹名称后，需在画布中重新选择图片。

`scrapbook-postcard.svg` 与展示示例中的 `postcard.svg` 使用同一幅插画。两个目录各自保留副本，便于分别复制使用。

主题操作见 [功能指南](../FEATURE_GUIDE.md#画布主题)。浏览器设计原型见 [主题设计与原型](../design/README.md)。
