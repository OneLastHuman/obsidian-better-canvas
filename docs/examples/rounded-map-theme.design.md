# 大圆角节点主题：风格定位原型

设计问题：为 Better Canvas 新增一种偏思维导图、流程图的视觉方向，以大圆角矩形、粗描边和清晰连线为共同语言。Miro / Xmind 是用户给出的气质参考；本原型是独立设计，不是对应产品的界面复刻。

用户认可整体风格，采用 A「软糖白板」及六种功能预设，已接入插件的画布主题与节点样式入口。预设通过不同形状表达不同功能，不能只是圆角矩形的配色变体。HTML 保留为独立风格探索工具。

## 打开原型

从仓库根目录运行：

```bash
python3 -m http.server 4177 --bind 127.0.0.1 --directory docs/examples
```

打开 `http://127.0.0.1:4177/rounded-map-theme.prototype.html`。也可以直接用浏览器打开该 HTML 文件。页面自包含，不需要安装依赖或加载远程资源。

- `?variant=A`：软糖白板。
- `?variant=B`：分支图谱。
- `?variant=C&scene=flow`：模块流程的流程图场景。
- `?variant=A&scene=presets`：六种功能形状总览，也是无参数打开时的默认场景。
- 页面左侧或底部箭头切换方案；键盘左右键也可切换，输入控件聚焦时不拦截方向键。
- 同一方案可以切换思维导图、流程图、深浅色画布，并调整圆角、描边和连线。
- 点击节点查看选中轮廓及连接点。微调只保存在内存；切换方案恢复该方案默认参数。

## 三个方向

| 方向 | 节点与层级 | 色彩与背景 | 连线 | 默认参数 |
| --- | --- | --- | --- | --- |
| A 软糖白板 | 实色中心、浅彩主干、留白末级，左对齐 | 奶油黄、雾蓝、浅绿、陶粉；暖白点阵 | 统一墨色曲线 | 27 px 圆角、3.5 px 描边、无投影 |
| B 分支图谱 | 深色中心、淡彩主干、轻边框末级，居中 | 同一分支同色；浅绿白底 | 继承分支颜色 | 21 px 圆角、3 px 主干描边、无投影 |
| C 模块流程 | 编号与标题分层，强调独立步骤 | 明亮色块；淡方格 | 圆角折线，流程场景带箭头 | 29 px 圆角、4 px 描边、5 px 硬阴影 |

后续预设以 A 的柔和配色、深色粗描边和圆化转角为基础。B 的分支配色与 C 的硬阴影仍保留为最初的风格对比方向。

正式实现采用用户微调后的 33 px 圆角上限与 4 px 描边。深色版本改为中性石墨画布、柔和粉彩节点、深色文字及轮廓、浅灰蓝连线。文档波浪与左右侧边使用切线连续的曲线接点，避免左下角折痕；实际节点、预设缩略图和静态导出共用路径。

## 六种功能形状

| 预设 | 轮廓 | 功能 |
| --- | --- | --- |
| 起止 / 主题 | 胶囊形，两端圆弧 | 流程的开始、结束，或思维导图中心 |
| 步骤 / 任务 | 圆角矩形 | 操作、任务与普通概念 |
| 判断 / 分支 | 四角圆化的菱形 | 条件判断；是、否写在对应连线上 |
| 流转 / 下一阶段 | 宽箭头形 | 阶段推进、交接与流转；箭头是节点本身的轮廓 |
| 输入 / 输出 | 圆化转角的平行四边形 | 收集信息、接收数据、输出结果 |
| 文档 / 产出 | 波浪底文档形 | 纪要、笔记、报告等成果 |

总览可以点选各预设查看说明，也可用“统一颜色”验证仅靠轮廓的区分度。流程示例使用全部六种轮廓：开始筹备 → 收集报名 → 判断人数；否分支返回报名，是分支进入安排活动 → 交流阶段 → 讨论纪要。

在思维导图或流程图中，先选中节点，再点左侧预设缩略卡片即可替换形状与样式，原有标题和说明保留。状态只存在当前页面内存中；“恢复这套方案的默认值”同时清除当前场景的预设覆盖。该交互没有连接 Obsidian 数据。

## 范围与落地约束

- 当前以本机桌面原型的视觉效果为验收范围；按用户要求，不再进行响应式布局研究、适配或测试。
- 原型独立绘制 HTML 内容、SVG 节点轮廓与连线，不导入生产代码，不证明 Obsidian 运行时兼容性。
- 深色按钮只预览画布配色；外层设计工作台保持浅色。
- 窄屏重排图形并将末级信息并入主干，保留四条中心分支；流程图重排为竖向步骤与侧边回路。
- 选中状态沿节点形状显示细轮廓，保留填充色；输入输出、文档和箭头的示意连线端点按视觉轮廓作局部调整。
- 正式实现复用现有 Canvas 主题入口、矩形交互几何与节点样式数据模型，详见 `docs/STYLE_DEVELOPMENT.md`。
- 正式节点使用容器裁形、锚元素 mask 描边及按形状计算的内容内边距；静态导出复用同源路径。原生矩形端点可能与斜边之间存在间隙；长文字在菱形和箭头中的自动尺寸策略尚未定义。
- “节点圆角”调节各形状的转角柔和程度；胶囊两端保持半圆。节点自身的箭头形不通过卡片旋转模拟。
