# README sample canvases (English)

These canvases match the English screenshots on the repository home page. Content is synthetic and written for the reading-circle and reading-note scenes.

## Open the samples

1. Create a folder named `Better Canvas Showcase` at the root of your vault.
2. Copy the six `.canvas` files and `postcard.svg` from this folder into it.
3. Enable Better Canvas.
4. Open any canvas in Obsidian.

`scrapbook.canvas` references `Better Canvas Showcase/postcard.svg`. If you rename the folder, point the image node at the new path.

| File | Scene | Theme |
| --- | --- | --- |
| `soft-notes.canvas` | Collect ideas, excerpts, and actions | Soft Notes |
| `rounded-map.canvas` | Plan a reading-circle flow | Gummy Whiteboard |
| `research.canvas` | Connect sources, annotations, and claims | Paper Research |
| `sketch.canvas` | Turn a question into a small experiment | Hand-drawn Whiteboard |
| `scrapbook.canvas` | Keep a reading moment | Scrapbook |
| `mind-map.canvas` | Break a plan into branches | Default |

The samples keep pre-arranged sizes and positions and disable auto-sizing on their nodes. New cards still follow the plugin settings and creation rules.

All text is synthetic; quotations do not borrow from real authors or books. The illustration reuses the repository's `scrapbook-postcard.svg` and needs no network access.

The Chinese set lives in the parent folder.
