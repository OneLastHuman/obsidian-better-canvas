# README 示例画布

这组画布对应 [Better Canvas 首页](../../../README.md)的产品截图。内容围绕读书会与阅读笔记编写，适合直接编辑和试用主题。

## 打开示例

1. 在 Vault 根目录新建 `Better Canvas 展示` 文件夹。
2. 将本目录的 6 个 `.canvas` 文件与 `postcard.svg` 复制到该文件夹。
3. 启用 Better Canvas。
4. 在 Obsidian 中打开任意示例。

`scrapbook.canvas` 引用 `Better Canvas 展示/postcard.svg`。如果更换文件夹名称，需要在画布中重新指定图片文件。

| 文件 | 场景 | 主题 |
| --- | --- | --- |
| `soft-notes.canvas` | 收集灵感、摘录与行动 | 柔软便签 |
| `rounded-map.canvas` | 规划读书会流程 | 软糖白板 |
| `research.canvas` | 连接材料、批注与观点 | 纸本研究 |
| `sketch.canvas` | 从问题推导一次小实验 | 手绘白板 |
| `scrapbook.canvas` | 收藏阅读片刻 | 拼贴手账 |
| `mind-map.canvas` | 按分支拆解计划 | 默认 |

示例保留预先编排的尺寸与位置，关闭了各示例节点的自动尺寸。新建卡片仍遵循插件设置与创建规则。

所有文字均为合成示例；引文没有冒用真实作者或书籍。插画复用仓库的 `scrapbook-postcard.svg`，不需要访问网络。
