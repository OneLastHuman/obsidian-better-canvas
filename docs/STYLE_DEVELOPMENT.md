# 节点样式开发指南

开发节点面板、形状、边框、颜色或文字排列时，先按本文检查数据和渲染边界。测试要求见 [测试与验证规范](TESTING.md)，分支与审查要求见 [仓库治理规范](REPOSITORY_GOVERNANCE.md)。

## 开发边界

- 面板使用插件自己的 DOM，可独立设计布局。
- 节点卡片的视觉由 CSS 绘制。连线端点、框选、手柄和导出几何沿用原生矩形模型，不改 Canvas 引擎。
- 样式入口挂在原生 `.canvas-controls` 控件栈。挂载前必须检查容器是否存在；容器不存在时跳过挂载。
- 不得 patch 或替换原生节点右键菜单。原生菜单同时承载 Obsidian 操作和其他插件的条目。

## 节点数据与渲染

- 状态写入 `bcShape`、`bcBorderStyle`、`bcTextAlign` 和 `styleAttributes`。DOM 只显示数据的渲染结果。
- 修改节点数据后，调用 `requestSave()` 并重新渲染装饰。
- 裁形使用 `.canvas-node-container` 的 `clip-path`。描边使用定位锚元素上的 mask 环。
- 不得裁剪定位锚元素，否则会裁掉描边环和手柄。
- 形状连接顶点按四边中点约定处理。预览与真实渲染复用同一套常量。

## 样式面板

### 选项与显示

- 通用选项定义集中在 `src/node-visual-style.ts`。
- 组合预设排在最前，用缩略卡片展示颜色、形状、边框和文字排列，不在卡片上印选项名。
- 形状使用可视图元；边框和文字排列使用图标分段控件。
- 点击选项立即应用到全部选中节点。同一属性存在不同取值时，必须提供可访问的混合状态。
- 面板使用主题变量，并将位置限制在视口内。Esc 或外部点击关闭面板。
- 面板跟随当前节点选区。连线选区，以及节点与连线混合选区，不进入节点样式面板。
- 自动调整尺寸通过“切换所选节点自动调整尺寸”命令按节点控制，不在样式面板中提供开关。

### 从预设创建卡片

- 空选区可打开面板。点击预设会在视口中心新建空白文本卡片；拖入当前画布则在落点新建。
- 无选区时，单项样式控件禁用；选中节点后启用。
- 所有主题预设复用同一建卡入口。建卡和样式应用共用一步撤销。
- 拖放不得改写原选区节点的样式。取消拖动、落在画布外或处于只读状态时，不创建卡片。
- Canvas 视图关闭时，关闭面板并清理拖放监听。重复打开不得重复注册监听。

## 主题实现参考

### 柔软便签

6 种预设和曲线定义在 `src/soft-notes-style.ts`。主题通过 `bcTheme: "soft-notes"` 保存，节点通过 `bcSoftNotesPreset` 保存预设。

实时节点使用同源 SVG `objectBoundingBox` 裁剪。缩略图与完整导出复用同一路径；视口导出必须携带裁剪定义及内嵌字体。

柔软便签只裁剪文本节点的容器，始终隐藏卡片描边和阴影。编辑器专用样式放入同源 iframe 的 body，避免 Obsidian 的 head 同步机制移除样式。

### 软糖白板

`bcTheme: "rounded-map"` 的 6 种组合定义在 `src/node-visual-style.ts`。应用时复用通用样式字段和颜色。

`src/rounded-map-style.ts` 按节点尺寸生成路径。以下位置复用该路径：

- 容器的 CSS `clip-path: path(...)`。
- 定位锚元素的 mask 描边。
- 预设缩略图。
- 静态导出。

尺寸变更时重新计算装饰。切换主题或卸载时，移除私有 CSS 变量。路径只改变视觉轮廓，原生矩形交互几何保持不变。

设计背景与原型见 [主题设计索引](design/README.md)。

## 新增样式的完成条件

1. 添加选项或数据字段，并接入解析和 `decorateCanvas` 装饰。
2. 在 `styles.css` 中补齐预览与节点渲染样式。
3. 补充测试，并执行 [标准本地检查](TESTING.md#3-本项目的标准本地检查)。
4. 在 Obsidian 中验证深浅色外观及本次改动涉及的交互。
5. 更新 [功能指南](FEATURE_GUIDE.md) 和 [功能整合矩阵](INTEGRATION_MATRIX.md)。README 的更新范围按仓库治理规范执行。
