# Excalidraw-inspired Canvas theme — design prototype

This is an **opt-in visual prototype** for Better Canvas, implemented as an Obsidian CSS snippet rather than a standalone web page. It does not change the plugin's default appearance.

## Design principles

1. **Content is the focal point.** The canvas stays quiet; toolbars and settings retain Obsidian's normal UI typography and controls.
2. **Ink before decoration.** Dark outlines and readable text establish structure. Avoid gradients, glass effects, oversized shadows, and ornamental UI chrome.
3. **Pastel fills encode grouping.** Use a small, repeatable set of low-saturation fills rather than assigning a unique color to every card.
4. **Typography has roles.** A sketch-style font is used only inside canvas card content; controls, menus, and settings remain in the host UI font. If Excalifont or Comic Shanns is not installed, the stack falls back gracefully.
5. **Edges explain relationships.** Keep lines legible and restrained. Arrow direction and node placement carry meaning; line decoration should not compete with labels.
6. **State must remain clear.** Selection and focus use a visible accent ring with sufficient contrast, including in dark mode.
7. **Respect the host theme.** Light and dark modes use different surfaces and line colors; this prototype does not force a white canvas in dark mode.
8. **Be honest about fidelity.** Excalidraw's characteristic irregular strokes are generated by its drawing engine. CSS alone cannot reproduce Rough.js geometry, so this prototype adopts its typography, ink/paper contrast, palette, and visual restraint without claiming pixel-perfect hand-drawn outlines.

## What's included

- Paper-like dotted canvas background.
- Ink outlines and low-elevation cards.
- A sketch-inspired font stack for card content only.
- Muted pastel fills using existing Better Canvas node color data.
- High-contrast selection/focus states.
- Light/dark adaptations and reduced-motion handling.

## Try it in Obsidian

1. Copy `excalidraw-inspired-canvas.css` into `<Vault>/.obsidian/snippets/`.
2. Open **Settings → Appearance → CSS snippets** and enable it.
3. Open a Canvas with Better Canvas enabled; compare normal, colored, selected, and dark-mode nodes.
4. Disable the snippet to revert immediately.

The six `.bc-sketch-*` palette selectors are reserved hooks for a later integration with Better Canvas custom node classes; they are not presented as a new settings feature in this prototype.

## Prototype acceptance checklist

- Card text remains readable at normal zoom and when zoomed out.
- The canvas background does not reduce contrast for embedded files or image nodes.
- Selection/focus is visible without a large glow.
- Dark mode does not introduce a bright paper rectangle.
- Node colors remain distinguishable but subdued.
- Native Obsidian menus and settings are unchanged.
- Test in the supported Obsidian versions before considering this for production.

## Next step after visual review

If the direction is approved, integrate the palette as an explicit Better Canvas appearance preset and verify its behavior against actual Canvas DOM and persisted node attributes. Do not make it the default until desktop and mobile rendering have been checked.
